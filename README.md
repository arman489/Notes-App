# 📝 MERN Notes App

A full-stack Notes Management Application built using the MERN Stack with secure JWT Authentication, CRUD operations, Search functionality, and a responsive UI.

## 🚀 Features

- User Registration & Login
- JWT Authentication
- Protected Routes
- Create Notes
- Read Notes
- Update Notes
- Delete Notes
- Search Notes
- Responsive Design
- Secure User-specific Notes

## 🛠 Tech Stack

### Frontend
- React.js
- Tailwind CSS
- React Router DOM
- Axios
- React Toastify

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## 📂 Folder Structure

frontend/
backend/

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/arman489/Notes-App.git
```

### Install Dependencies

```bash
cd frontend
npm install

cd backend
npm install
```

### Run Project

Backend

```bash
npm run dev
```

Frontend

```bash
npm run dev
```

## 🔐 Environment Variables

Create a `.env` file in the backend.

```env
PORT=***
MONGODB_URL=your_mongodb_url
JWT_SECRET=your_secret_key
```
